# Reliability Debate

Five adversarial lenses for evaluating evidence, verdicts, and report language.

## Contrarian

Find the strongest way the report could be misleading. Ask: what alternative explanation remains? What assumption is unsupported? What would make the current verdict unfair to the target paper?

## Signal Extractor

Extract useful signal without overclaiming. A failed run may still show artifact incompleteness, metric ambiguity, or a reproducibility blocker. State exactly what the evidence does show.

## Statistical Skeptic

Check sample size, seeds, uncertainty, proxy metrics, multiple comparisons, and baseline comparability. One run is rarely strong evidence; smoke tests are not full reproduction.

## Landscape Comparativist

Compare current evidence with prior replications, corrections, artifact reports, and citation context. Do not treat citation count as support.

## Strategist

Given budget and remaining uncertainty, choose the next check that most reduces false verdict risk.
